# Calendario (.ics)

Plugin para Gestor DeCA 1.5.0 o posterior.

## Qué hace

- **«Calendario (.ics)»** en cada envío y página *Calendario* para exportar varios (desde/hasta, tipo, incluir borradores o anulados).
- Se importa en Apple Calendar, Google Calendar, Outlook y cualquier calendario compatible.
- Cada evento lleva la referencia, el cliente, la carga y las descargas, la mercancía, el conductor y el vehículo, las instrucciones y el enlace al documento.

## A tener en cuenta

- No se conecta con Google, Apple ni Microsoft ni pide credenciales.
- Los documentos solo tienen fecha: los eventos son **de día completo** y lo indican; no se inventan horas. Los anulados se excluyen salvo que se incluyan expresamente (aparecen como cancelados).
