# Plantillas de transportes

Plugin para Gestor DeCA 1.5.0 o posterior.

## Qué hace

- Guarda los transportes habituales (ruta entre almacenes, cliente recurrente, mercancía e instrucciones) como **plantillas**, desde cualquier envío (*Guardar como plantilla*) o desde cero.
- Al registrar un envío, **«Crear desde una plantilla»** rellena los campos y los marca para revisarlos.
- Vehículo y conductor **preferidos** opcionales: solo se rellenan si lo confirmas al usar la plantilla.
- Página de plantillas para usar, editar, renombrar y eliminar, con el número de usos.

## A tener en cuenta

- Una plantilla nunca es un documento: el envío nuevo tiene su propio número, QR, fechas y estado. No se copian el estado, el token, el historial ni las fechas, ni datos propios de cada viaje (peso, bultos, fecha, albarán, reservas).
