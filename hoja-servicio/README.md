# Hoja de servicio

Plugin para 7DeCA 1.5.0 o posterior.

## Qué hace

- **«Hoja de servicio»** en cada envío: PDF sencillo para imprimir o ver en el móvil con fecha, conductor y teléfono, vehículo y remolque, direcciones de carga y descarga (de Ubicaciones frecuentes), contactos, mercancía, peso, bultos, instrucciones y el **QR del documento oficial**. Si hay ruta calculada (plugin Rutas), los km y la duración.
- Se puede enviar con los plugins de WhatsApp y correo (*Enviar también: hoja de servicio*).

## A tener en cuenta

- Está marcada como **hoja operativa interna**: no sustituye al DeCA ni a la carta de porte, no altera el PDF oficial y no inventa datos (lo que falta se omite o se indica como «no indicado»).
